# Jungle Math

An addition game for iPad, built as a static web page. Oranges fly in from both sides and the child picks the total. 13 levels go from sums up to 5 to sums up to 99, with crates standing in for tens.

Play: https://ohadasulin.github.io/math-addition/

- Preview any level with `?level=12` in the address.
- Sounds are listed in `sounds.js`. To add one, replace its WAV and keep the file name.
- `tools/` holds the scripts that prepare images and cut the music. They need the raw files, which aren't in this repo.
